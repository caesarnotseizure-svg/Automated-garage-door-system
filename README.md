# Automated-garage-door-system
Employing Arudino UNO , this is a simple sytem that can open doors upon sensing nearby moving objects.

The automated garage door system system is an automated system designed to control vehicle entry and exit. An ultrasonic sensor detects an approaching vehicle by measuring the distance using ultrasonic waves. It sends this information to the Arduino Uno, which processes the signal. When a vehicle is detected within the specified range, the Arduino activates the servo motor to open the barrier. A buzzer provides an alert, improving safety and convenience while reducing manual operation.
